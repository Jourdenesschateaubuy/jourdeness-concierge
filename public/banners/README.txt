Jourdeness Home Banner Phase 2 Package

使用方式：
1. 將 app/page.tsx 覆蓋到你的 Next.js 專案 app/page.tsx
2. 將 public/ip/ 複製到你的專案 public/ip/
3. 將 public/banners/ 複製到你的專案 public/banners/
4. 執行 npm run dev

本版重點：
- 已加入 8 張首頁 Banner 圖片素材
- Banner 圖片不含文字，網站會用文字疊上去
- 保留首頁導購型分區、商品詳情、清單、Google Sheets 送單
- 冷杉化妝水 / 保濕乳與冷杉任選組合保留即期優惠標籤
